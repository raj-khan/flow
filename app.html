isketch: sketch it, hand it to your agent

The diagram editor. It runs in the browser, so this page alone holds no diagram. For AI agents: read %SITE_URL%/llms.txt first.

For AI agents: show someone a diagram

  1. Write the diagram as .flow text: id = process "Name" for a shape, a -> b : label for a connection. The format: %SITE_URL%/docs/format
  2. Link it as %SITE_URL%/new#flow=t followed by the .flow text as base64url-encoded UTF-8 with no padding.
  3. Give the person that link. Opening it draws the diagram, ready to edit.

No account, API or server is needed, and isketch.online hosts no publish API. To read a link: after #flow= comes t and base64url text, or z and base64url of raw DEFLATE-compressed text.
